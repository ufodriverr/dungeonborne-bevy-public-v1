# How to play

Start `dungeonborne.exe` with your `_data` folder next to it (see [README.md](README.md)). The title
screen has **Play** (the game: pick a class, the stash, then a run) and **Test Arena**.

Windows 10/11 64-bit and a GPU with Vulkan or DirectX 12. The castle is large: entering a map
takes a few seconds behind a loading cover.

## Controls

Every key can be changed under **Settings** (title screen or pause menu).

| Key | Action |
| --- | --- |
| W A S D | move |
| Left Shift | sprint |
| Left Ctrl | crouch |
| Space | jump |
| Left click | light attack; hold for a heavy (charged) attack; with a staff, hold to cast |
| Right click | block; aim a crossbow; recharge a staff |
| Q, E | class skills (pick them on the stash screen) |
| F | interact: chests, items, doors, levers, portals, altars |
| Tab | inventory |
| 1, 2 | healing and protection potions |
| 3 to 6 | flasks |
| 7 | torch: take it out, left click throws, right click raises it |
| R | reload the crossbow |
| X or mouse wheel | switch weapon set |
| G / H | drop one / drop all of an item (inventory) |
| Delete | destroy an item (inventory) |
| Esc | pause menu: resume, settings, abandon run, quit to title |

## A run

Pick a class, check your gear and skills on the stash screen, and choose a map. Fight through it,
open chests (some bite back), loot what you can carry, and leave through an extraction portal
before the run's time runs out; when it does, whoever is still inside dies. You keep everything
you extract with; die and you drop what you carried. The merchant on the stash screen sells for
gold.

## Test Arena

Every monster kind on its spot (back 5 seconds after dying), chests, altars, the training dummy
and every regular weapon on tables.

| Key | Action |
| --- | --- |
| F1 to F8 | switch class: Fighter, Swordmaster, Priest, Rogue, Wizard, Death Knight, Lich, Druid |
| R | respawn after death |

## Saves

- `_data/save/profile.json`: your character, stash and gold
- `_data/save/settings.json`: your settings
