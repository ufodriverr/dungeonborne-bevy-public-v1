# Legal notice

## Project and game content

Dungeonborne on Bevy is a free, unofficial fan-made engine reimplementation of **Dungeonborne**.
The maintainer develops and distributes it as a personal, noncommercial project for learning and
preservation.

The project distributes its implementation and documentation. Game executables, archives,
encryption keys, mappings, maps, models, animations, textures, effects, interface art, fonts,
text, sounds, music and voices are not included.

The application reads game data that the user has extracted from a copy installed on their own
PC. It interprets the game's data tables, behaviour trees and effect data as data; it does not run
the original client's machine code and contains no Unreal Engine code. This repository contains
no code that decrypts game files. Screenshots, extracted data and other game-derived outputs are
not licensed by this project and are excluded from its distributions.

The application is single-player and offline. It never connects to the game's servers, and it
does not interact with, bypass or modify the game's anti-cheat or its executable protection.

## Your own installed copy is required

Use the application only with data you extracted yourself from a copy you installed yourself. Do
not download extracted data from someone else, and do not share, upload or redistribute extracted
data, game files, keys, mappings or content dumps, including in issues, pull requests, releases or
CI artifacts. Report bugs in your own words with a minimal log that contains no game content or
private filesystem paths.

This project supplies no game downloads, extracted data, keys, mappings or links to obtain them.
